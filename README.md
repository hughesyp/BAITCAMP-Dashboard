# BAITCAMP Dashboard

Dashboard for the people marketing BAITCAMP: 30-day social and revenue stats, a post composer that publishes through Blotato, per-post performance, targets, brand voice with an AI caption writer, a content calendar, media library, ideas board and revenue-share statements.

- **Front end:** Vite + React + TypeScript + Tailwind (`src/`)
- **Back end:** Supabase (auth, Postgres with row-level security, storage, Edge Functions in `supabase/`)
- **Hosting:** Azure Static Web Apps

See [SETUP.md](SETUP.md) for setup, API keys and deployment.

```powershell
npm install
npm run dev
```
